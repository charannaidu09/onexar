# Onexar website design concept

A single-page redesign concept for onexar.com, built in Onexar's existing brand colours and fonts (Hanken Grotesk, DM Sans).

- `index.html` holds the whole page (HTML, CSS and JavaScript)
- `fonts/` holds the font files, served locally

Prices, charts and the copy-trading leaderboard on the page are sample data for illustration, not live market data.
